# security-lab

各レイヤを自分で実装し、壊し、守ることで、コンピュータとネットワークのセキュリティを原理から理解するための実験リポジトリ。

> 作って理解する。壊して理解する。守って理解する。

## 方針
- **自作する**: ライブラリに頼る前に、まず仕組みを自分で書く（学習用。本番利用はしない）。
- **攻撃と防御をセットにする**: 攻撃実験には、必ずそれを検知・防御する側の実験を対にする。
- **記録を残す**: 実験ごとに `templates/EXPERIMENT.md` の形式でノートを書く。うまくいかなかったことも成果として残す。
- **隔離環境でのみ行う**: ルールは [`ETHICS.md`](./ETHICS.md)。
